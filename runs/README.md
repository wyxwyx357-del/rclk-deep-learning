# 本地测试记录

本目录保存可由Git跟踪的实验摘要。每次测试用一份Markdown文件，按日期和任务命名；填写[模板](TEMPLATE.md)，写明代码版本、输入口径、运行状态、汇总结果和限制。未运行的测试不要写成已通过。

只记录汇总数值和不含患者身份的配置。患者ID、姓名、逐例结果、临床原始表、视频、模型权重和详细输出放在`outputs/`、`data/`或`checkpoints/`等被忽略的目录，不提交到Git。记录可以指向这些本机路径，但本地Git历史本身不是数据备份。

保存新记录后，用`git add runs/<记录文件>`和`git commit -m "Record <测试名称>"`更新本机历史。无需设置远端或执行`git push`。
