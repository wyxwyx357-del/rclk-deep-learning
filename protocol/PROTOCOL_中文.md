## 2. 仍缺少什么

1. **输入读取已完成，训练装配尚需实现。** `sequence_inputs.py`已把正式数组、1171帧掩码、坐标和真实时间接起来，并通过295例验收。患者分折、训练折标准化、批处理和静态临床输入仍需在训练程序中连接；目前没有可直接启动正式TCN交叉验证的脚本。
2. **必需的训练约束：所有处理在训练折内拟合；测试折只评价。** 现有Logistic划分可用，序列标准化、早停、选参数和随机种子仍要落到实现中。
3. **临床来源核对仍有未闭合线索。** 既有诊断记录中，姓名/日期来源风险并集35例，其中19例当前移植日期缺失、1例检查到移植63天。它们不是35例已证实错配；指定源表连接检查已经通过，但是否同次移植尚不能仅靠连接证明。输入工程可同步进行。逐例核对身份、检查及结局是否对应同次移植，记录已确认、仍未确认、已确认错配三种状态。已确认错配者在冻结主数据前按来源证据修正；无法修正的已证实错配不能按原标签参与建模。仍未确认但未证实错配者保留原295例主分析并标记，预先安排敏感性分析；不能按AUC或模型表现删病例。若名单或标签确需修正，所有比较共同使用新版本并重新生成患者分折。
4. **35例不是全部临床来源疑点。** 既有来源审计另记录33例胚胎类型编码来源日期差异，其中19例不在上述35例中；还有54例的胚胎类型来源日期未记录。它们是编码溯源线索，不代表已证实的标签错配。现有胚胎类型也不等于胚胎等级。首轮沿用同一版临床变量供所有模型公平比较，明确增量仅相对这个有限基线；若核对后修正胚胎类型，所有比较组共同更新。胚胎质量整理作为独立版本，不在网络结果出来后只增强某一组。外部验证目前也没有，不属于本轮内部探索必须新增的实验。

不追加全队列人工视频复核、追踪材料点证明、全套运动校正或大范围模型海选。此前运动抽查已足够支持“不新增一刀切屏蔽”，但不替代上述输入/临床来源工作。

## 3. 固定输入口径

使用未做整段聚合、未作频带过滤的正式有符号变化率：

| 量 | 源字段 | 原形状 | 含义及单位 |
|---|---|---|---|
| R | `current_qc_radial_strain_rate_s` | T×2×S | 前后壁径向点距相对变化率，s⁻¹ |
| C | `qc_cavity_width_strain_rate_s` | T×S | 前后壁采样带中心距相对变化率，s⁻¹；不是直接分割的真实宫腔宽度 |
| L | `qc_longitudinal_wall_strain_rate_s` | T×2×(S−1) | 沿壁相邻中心距相对变化率，s⁻¹ |
| K | `qc_wall_curvature_change_rate_mm_inv_s` | T×2×S | 物理曲率变化率，mm⁻¹/s；两端结构性缺失 |

先保留源数组已有的正式无效值，再对`05_radial_tracking_corrected`中的`p3_topology_risk_frame`对应帧屏蔽全部四类量；此字段与最终07 QC中的`p3_topology_risk`在295例逐帧一致。严格复用正式帧号，不扩大到相邻帧、不加入自动候选/QC2级屏蔽，不根据预测效果改规则。

拟采用以下单一输入转换方案，不把转换方法加入结局驱动搜索：

- **空间：** R/C映射到宫颈→宫底的8个等距坐标；L的坐标是原相邻点坐标的中点，映射到目标8点之间的7个中点；K使用与R相同的8点坐标并保留无定义端点。仅在同帧、同壁、原始相邻且均有效的两位置之间线性插值，不外推、不跨无效位置补洞。原有空间点数仍保存为质量变量。
- **时间：** 统一到35 Hz，即本队列最高原生帧率；这样不做降采样，不额外引入低通滤波选择。时间为原帧号/fps，目标网格不超出最后原始时间。只在同一通道连续有效的相邻原帧间线性插值；跨缺失或拓扑风险帧保持缺失。35 Hz不是新增测量精度，也不是最优生理采样率的结论。逐点保存原始观测/插值标记、两个原帧来源索引和插值权重；重新采样后的时点不得计作新增独立观测。
- **数值：** 每个R/C/L/K家族各用训练患者估计一个均值和标准差，前后壁和位置共享该家族尺度；先求每位患者的有限值一阶/二阶矩，再等患者权重合并，避免长视频主导尺度。不做患者内z分数，不按患者压成相同幅度，不自动削峰。尺度过小按固定数值下限1e-8处理并记录。
- **缺失：** 标准化后无效值填0，同时提供逐点有效掩码。0仅为计算占位，不代表测得没有形变。时间填充另有padding掩码，不能混同有效零值；K结构性端点单独记账。
- **连续段：** 如果某时间点R/C/L任一家族完全无有效位置，则视为该段中断；网络分别处理两侧连续段，患者内汇总，不拼接卷积。局部位置缺失保留掩码。仅为批处理补齐长度，不改变时间；不得用窗口增加“独立样本量”。不足一个感受野的短段允许零填充计算，必须排除填充位置的池化。
- **防止K比较混杂：** 288例两种网络都按相同RCL有效段切段；K局部缺失只由K掩码表示，不能给RCLK模型额外删去RCL时段。

读取与35 Hz转换已实现，295例名单、原始/目标时长、时间严格递增、原始观测与插值占比、来源索引、缺失/拓扑帧不得被插值跨越、原始数组正式汇总中位数等检查均通过。抽查包含6、7、8点和拓扑病例；S=8且fps=35的原始R与转换R逐元素一致。**批处理补齐长度不改变同一患者的网络输出**仍待TCN程序实现后检查。目标时间点的插值比例中位数约85.7%；这是网格加密，不是新的独立观察。无需重做追踪实验。

## 4. 固定比较组

H为既有9项临床变量＋医生正/反向次数（原Logistic的B组）。8例医生次数不可数值化仍保留缺失并在训练折插补，不能当0；周期类型在该队列恒定。所有组共享H，避免变更临床信息制造增量。

| 名称 | 输入与模型 | 目的 |
|---|---|---|
| M0 | H，原正则化Logistic | 背景基线，可复用相同名单分折的既有折外预测 |
| M1 | H＋F01/F07/F09，正则化Logistic | RCL聚合基线；需新跑，因为旧C组含F15 |
| M2 | M1的输入＋固定简单时空统计，正则化Logistic | 判断便宜的统计量是否已足够 |
| M3 | M1的输入＋RCL小型TCN表示，联合训练线性分类头 | 主要待检模型 |
| MQ | M1的输入＋质量/运动代理变量，正则化Logistic | 检查质量信息本身的预测能力 |

主要比较预先指定为M3−M1；M3−M2和M3−MQ为必要解释比较。M3保留同样三项聚合值，因此主要问题是“在已有幅度汇总上，序列还增加多少信息”。既有ER/小MLP阴性结果不必再重跑来填表。

M2统计固定为5个通道组（前/后壁R、C、前/后壁L），每组6项，共30项：有效值绝对值中位数、绝对值P95、正值比例、1秒滞后自相关、各空间位置绝对值中位数的IQR、相邻空间位置零滞后相关的中位数。用与TCN相同的坐标/时间转换后数据；相关使用有符号数据，按位置分别算后取中位数，常数序列记缺失。1秒滞后对只在中间整段均有效时计入；每个相关至少70对有效配对，位置IQR至少2个可用位置。该门槛是统计可计算性规则，不是严格传播判定。所有缺失在训练折插补，不在全295例先选特征。

MQ固定12项：原视频时长、原fps、原S、R/C/L各自无效率、内部平移速度中位数(px/s)、内部转动速度绝对值中位数(deg/s)、FB误差P95的时间中位数、PCC时间中位数、最终QC2级帧比例、35 Hz目标网格中插值时点比例。运动和QC字段来自最终07 QC的`global_translation_step_px`、`global_rotation_step_deg`、`pair_fb_error_p95_px`、`pair_mean_pcc`、`artifact_grade`；位移及转角按原fps转换，级别比例用`artifact_grade == 2`。插值比例按原帧来源索引/权重计算，不根据结局定义。QC2级含形变同步性等证据，不是独立伪影标签。当前内部运动代理不能把探头运动与真实共同组织运动分开，MQ即使阴性也不能证明不存在运动干扰。

## 5. 模型和仅4组参数测试

只选择一类小型TCN（时间卷积网络）：卷积沿时间寻找局部模式，扩张卷积连接较远时间点，多位置通道保留解剖位置差异。选择理由是参数可控、可明确规定时间范围、适合本次小样本探索；没有证据证明它在本数据上优于其他网络。[TCN原始方法论文](https://arxiv.org/abs/1803.01271)是结构依据，不是本研究有效性证据。

具体固定结构：R16＋C8＋L14=38个数值通道，附38个掩码，共76个输入通道；1×1卷积投影至宽度W；8个残差块，每块2个因果一维卷积，核宽3，扩张率依次1/2/4/8/16/32/64/128；ReLU和dropout，不使用依赖批次/填充统计的BatchNorm。每个块在真实padding位置重新置零。每个连续段独立卷积，随后对所有真实有效输出做患者级平均及最大池化，与训练折预处理后的M1静态输入拼接，单一线性头输出妊娠logit。

感受野为1＋2×(3−1)×(1＋2＋…＋128)=1021个采样点，首末跨度1020/35≈29.14秒。患者级池化覆盖全部保留时段，但不能据此声称模型学习了整段79秒的先后关系，更不能声称识别了120秒周期。W=8约0.4万参数，W=16约1.4万，实际总数随类别独热维数略变，执行时记录。

| 参数 | 固定值或测试值 |
|---|---|
| 网络宽度W | **8、16** |
| AdamW权重衰减（抑制过拟合） | **0.001、0.01** |
| 参数组合数 | **2×2=4组** |
| 学习率 | 0.001，固定，不叠加调度搜索 |
| dropout（训练时随机屏蔽部分隐藏单元） | 0.20，固定 |
| 批量 | 16位患者，不是16帧；每位患者损失权重相同 |
| 损失 | 未加类别权重的二元交叉熵；不做过采样 |
| 最多训练轮数 | 100 |
| 早停 | 内层验证交叉熵12轮无≥0.0001改善即停止；保留最低验证损失轮次 |
| 梯度裁剪 | 全局范数1.0 |
| 模型选择 | 5个内层验证AUC的均值最高；差≤0.005时选W较小者，再选衰减较大者 |

内层每配置一个预定种子；外层最终拟合采用3个预定种子取概率平均，不挑最好的种子。种子基值20261022、20261023、20261024，按repeat×1000＋fold×100偏移；内层仅用首个基值并加inner折号。外层重训轮数为选中配置5个内层最佳轮数的中位数（四舍五入，至少1轮），用全部外层训练患者，不观察外层测试损失早停。**345次拟合仅指295例主TCN**：4×75=300次内层拟合＋15×3=45次最终拟合；288例K比较和触发后的机制对照另计。此前CPU耗时估计来自当前`+cpu`环境，不能作为GPU运行估计。实现后先验证CUDA版PyTorch确实调用RTX 5060，再在预定训练折上作程序运行验收：加载一小批、完成前向/反向更新、确认损失有限、掩码与补齐行为正确，并记录实际显存和耗时；不看外层测试成绩，不以此调整参数网格，然后再估算完整运行时间并启动正式训练。不能把某次最好结果挑出来。

M1/M2/MQ沿用既有Elastic Net Logistic的16组网格和训练折处理，以相同患者分折评价。TCN静态输入的插补/独热也只能在各训练折拟合；不沿用在全295例拟合的变换器。[嵌套交叉验证方法说明](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)。

以上是预定候选，不是已经确定的最优参数。首轮不增加CNN/LSTM/Transformer竞赛；无增量时不继续扩大搜索范围直到出现阳性。

## 6. “相应机制”分成网络使用的信息与生理机制

训练后的高AUC、注意位置或热图不能证明子宫运动导致妊娠变化。先回答模型使用了哪些信息；生理因果机制需要独立证据。

只有M3较M1和M2的平均AUC均增加至少0.01，且相对二者各有至少2/3重复为正时，启动下列三个预先指定对照；这个阈值是节省计算的探索门槛，不是统计显著性或临床意义门槛。未达门槛则报告本模型未显示值得进一步拆解的序列增量。

| 对照 | 实施方式 | 能说明什么／不能说明什么 |
|---|---|---|
| 打乱时间顺序 | 每位患者每个连续段内，同步打乱全部空间/壁/量及其掩码；训练、验证、测试都按固定独立种子转换，并从头拟合相同4组候选 | 若性能降低，支持原时间组织有贡献；打乱也改变自相关/频谱，不能单独归因为传播或生理频率 |
| 去掉细空间分布 | 每一时间点、每个物理通道组以有效位置均值替换其所有有效位置值；原掩码保留，输入通道数和网络不变；重新训练 | 若降低，支持细空间分布在壁平均时间信号之外有贡献；不证明具体方向或速度 |
| 仅保留掩码与质量 | 所有序列数值置0、保留掩码，静态端加入MQ的12项质量量，网络相同并重新训练 | 若接近M3，警惕质量/缺失模式解释预测；不把内部平移代理当探头真值 |

所有对照使用相同分折、训练预算及最终种子。不能只在已训练网络的测试输入上打乱后就称作机制证据；那会混入输入分布突变的影响。性能差异仍报告患者配对区间，不只看点估计。不自动用“扣除共同运动”的残差作主输入，避免把真实组织形变一起去掉。

K作为预定次要分析：在同一288例上，将原分折按ID取交集并检查各折都有两类结局；两个模型都以H＋F01/F07/F09/F15作静态基线，分别加入RCL或RCLK序列，使用同一4组网格。这样考察的是K序列相对已含K聚合值的额外贡献。两组都需重新拟合；不能用295例AUC与288例AUC相减，也不能把7例缺K标记当额外主预测变量。

## 7. 评价、停止规则和交付

- 主指标：每次重复完整295例折外AUC，再取3次均值；同时报告每次重复、Brier分数和折外校准图。AUC增量与概率校准分开解释；不事后选分类阈值展示最优准确率。
- 区间：沿用既有10000次按结局分层的患者配对bootstrap，各模型及3次重复共用重抽样患者。不能把885个“患者×重复”当独立人。区间条件于既有折外预测，不包含完整重训与历次研究方案选择的不确定性。
- 每个患者的全部帧、连续段、任何未来切窗只能在同一折；每个患者每个重复仅一条最终折外概率。不得按帧随机划分。
- 临床来源敏感性分析预先固定：逐例核对后若仍有身份/同次移植未确认记录，主分析保留有标记者；次分析仅用来源已确认者，从同一患者分折按ID取交集，全部比较组重新拟合并继续做患者配对比较。必须报告各组保留人数与结局比例；该分析样本变小，不能把AUC绝对值与295例主分析直接相减。已证实错配按上文先修正或按证据处理，不混作“未确认”病例。
- 如果M3没有稳定优于M1/M2，结论是“本次预定小型TCN未显示明确增量”，不是所有时空模型都无效。若主要增量区间跨零，保留不确定性，不用个别高AUC折包装结果。
- 如果数值模型与质量对照相近，不增加运动校正来追求AUC；先回到具体高影响片段，确认是否存在可复现的测量失效，再决定是否修改QC。这是有触发条件的后续工作，不是现在新增全队列审查。
- 当前队列已经反复用于开发，即使嵌套CV也仍为内部探索；模型机制对照不能消除这项限制。

执行顺序：**输入读取器与295例验收（已完成）＋临床来源逐例核查及状态标记 → 冻结数据版本/本协议/配置和源文件哈希 → 配置CUDA版PyTorch并在训练折作GPU程序运行验收 → 跑M1/M2/MQ/M3和预定临床来源敏感性分析 → 完成288例K次要比较，并按预定门槛决定是否做机制对照。** M0历史预测只在病例/标签/分折未变时可直接复用；一旦临床核查导致任一项变化，M0及全部其他组统一重训。旧ER不作为新方案的输入或正式清理依据。

执行包需保存：病例与分折版本、源字段/掩码哈希、逐例原始与转换后有效率、训练折变换参数、4配置内层成绩及早停轮次、最终全部种子、参数量、逐患者折外概率、配对增量与条件区间、失败/停止记录。记录目的均对应防止错接、泄漏或挑结果，不新增无目的验证。
