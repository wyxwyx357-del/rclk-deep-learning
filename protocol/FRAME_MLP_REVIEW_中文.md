# 逐帧共享 MLP（DeepSets）与现有 TCN 的代码审查方案

状态：**仅实现代码，尚未运行真实患者训练。** 本方案是已完成 260 例来源确认子集上的一次探索性结构对照。原草稿 PR 的 211584 维展平 MLP 已撤回，不沿用其参数或结果。

## 固定比较口径

- 复用已有 `outputs/exploratory_260` 中完成的 M1、M3 折外预测，不重训 M1/M3。程序核对来源哈希、260 例患者、3 次重复 × 5 外折、患者折号，并记录既有逐患者预测文件的 SHA-256。该输出目录留在本地，不进入 Git。
- `FRAME_MLP` 使用与 M3 相同的正式 QC 后逐帧 R/C/L、有符号值、35 Hz 时间网格、每壁 8 个 R/C 位置及 7 个 L 相邻位置，以及同一套 H＋F01/F07/F09 静态输入。临床插补与编码、R/C/L 家族标准化只在相应训练折拟合。
- 直接复用 M3 的 `SequenceBank`、`prepare_fold` 和 `pad_patient_runs`：R/C/L 任一家族完全缺失的时点断开连续段，不作为模型时点；局部缺失保留逐通道有效掩码。每段右侧填充由独立的布尔 `time_mask` 标识，均值和最大池化都忽略填充。原观测与插值标记不另设网络输入，与 M3 一致。模型不使用时点顺序或绝对时长。
- 每个有效时点输入固定顺序的 38 个标准化有符号测量值及 38 个有效掩码。共享一层 **76→8** 的线性层、ReLU 和 dropout 0.2，在患者所有有效时点上做均值和最大池化，再与静态输入拼接至线性预测头。网络权重不随绝对时间位置变化。参数量在运行记录中保存。
- 固定 AdamW 学习率 0.001、权重衰减 0.01、批量 16、最多 100 轮、不加类别权重。每外折 5 个内折只用于以验证 log loss 早停，耐心 12 轮、最小改进 0.0001；外折以 5 个内折最佳轮数中位数重训 3 个固定种子并平均概率。**没有参数搜索。**
- 比较同一患者和分折的 `FRAME_MLP−M3` 与 `FRAME_MLP−M1` 折外 AUC、Brier 和配对条件 bootstrap 区间。逐患者预测与拟合详情仅写入 Git 忽略的本地 `outputs/`。

## 能回答的问题与边界

这是一项顺序无关的逐帧空间模式对照：DeepSets 汇总各时点的 R/C/L 状态；TCN 还可利用局部时序排列。两者模型容量和结构仍不同，因此结果不能单独证明时间顺序的因果作用，更不能证明识别到了生理蠕动波。AUC 高低仅限于当前 260 例和妊娠预测任务；不据此改变原追踪、QC、患者标签、冻结特征或已完成的 TCN 结果。

## 运行边界

外部代码复审前仅允许静态检查与合成输入单元测试；**不要运行 `scripts/run_frame_mlp.py`**。复审通过后才在本机用既有 35 例来源核查表执行预先固定的一轮患者级比较。`--out` 必须是新建或同一版本可续跑的本地忽略目录；默认与本机 `outputs/exploratory_260` 比较。

复审重点：共享层与无序池化是否真的不利用时点先后；完全无效时点、局部缺失和右侧填充是否正确处理；训练折预处理、内层早停和外层预测是否隔离；已有 M1/M3 折外预测是否按患者严格配对。
