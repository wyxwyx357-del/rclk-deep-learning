# 逐帧 MLP 与现有 TCN 的代码审查方案

状态：**仅实现代码，尚未运行真实患者训练。** 本方案是已完成 260 例来源确认子集上的一次探索性结构对照，不修改原 TCN、正式追踪、QC、患者标签或临床变量，也不根据结果删病例。

## 比较口径

- 使用已有 `outputs/exploratory_260` 中完成的 M1、M3 折外预测。程序要求来源哈希、260 例患者和 3 次重复 × 5 外折与该结果完全一致；不重训 M1/M3。该目录及患者级输出留在本地，不进入 Git。
- 新模型 `FLAT_MLP` 与 M3 共用 H＋F01/F07/F09 静态输入、正式 QC 后的逐帧 R/C/L、35 Hz 时间及每壁 8 个 R/C 位置和 7 个 L 相邻位置。临床插补与编码、R/C/L 家族尺度只在相应训练折拟合。
- 沿用 M3 的 R/C/L 完全缺失家族判定。完整缺失家族的时点所有通道标无效；其余局部缺失保留掩码。不补跨缺失值。每人按从视频开头起的真实秒数排列，不拉伸到相同视频时长。
- 统一右侧填充到 **2784 个 35 Hz 时点**，这是现有 295 例输入验收报告中的目标长度上限。超过该长度时直接报错，不自动截断。每个时点按固定顺序输入 38 个标准化有符号值和 38 个有效掩码，共 **211584 个展开输入**；未有效的数值位以 0 占位。原观测与插值标记目前不作为单独网络输入，与现有 M3 的做法相同。
- 一层宽度 4 的 ReLU MLP，dropout 0.2，接静态变量和线性输出头。AdamW 学习率 0.001、权重衰减 0.01、批量 16、最多 100 轮、不加类别权重。每外折 5 个内折只用于以验证 log loss 早停，耐心 12 轮、最小改进 0.0001；外折用内折最佳轮数中位数重训 3 个固定种子并平均概率。**没有参数搜索**。汇报内折 AUC、轮数、模型参数量及三轮完整患者折外 AUC、Brier、配对条件 bootstrap 区间。
- 主要结构对照是 `FLAT_MLP−M3`；同时看 `FLAT_MLP−M1`。同一批患者、同一分折和静态变量使差值可配对解释，但两种网络对缺失段的表示不同，而且 MLP 因定长展开拥有远多于 TCN 的参数。这不是严格等参数比较。负结果不能证明所有 MLP 无效，正结果也不能证明新的临床增益已在独立患者得到验证。

## 运行边界

审查前只允许静态检查及合成输入的单元测试；**不要运行 `scripts/run_flat_mlp.py`**。完成外部代码审查并确认方案后，才在本机使用已有 35 例来源核查表运行。程序默认对比本机 `outputs/exploratory_260`；`--out` 必须是新建或同一版本可续跑的本地忽略目录。所有逐患者预测、拟合详情和权重保持在 Git 忽略的 `outputs/` 下。

审查重点：是否真的与现有 M3 使用相同源患者和分折；定长展开的时间、空间、正负号、缺失及 padding 是否正确；折内预处理和外折概率是否隔离；模型维数和计算预算是否与“有意义的 MLP 结构对照”相称。如果认为这种高维直接展开的比较缺乏解释价值，应在训练前提出替代方案，并将任何固定长度变换写成新版本，不根据 AUC 临时修改。
