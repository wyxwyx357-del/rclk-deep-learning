# 295例逐帧输入读取验收

日期：2026-10-22。已实现`sequence_inputs.py`，只读取D盘正式输出，不修改源数组或追踪/QC。`accept_sequence_inputs.py`逐例运行并生成不含姓名的验收表。当前代码是输入读取及验收，不包含TCN训练、临床数据核查或完整交叉验证。

验收结果：295例R/C/L全部读取，288例K可读；14例共1171个拓扑风险帧已按冻结规则屏蔽。所有患者35 Hz目标时间严格递增，未超出原视频最后一个采样时间；来源帧最多相邻1帧，不跨风险帧生成有效值。每个R/C/L/K值的有限性与有效掩码一致，观测标记只出现在原帧及原空间点上。原始未插值、但已屏蔽风险帧的四类绝对值中位数仍与正式F汇总一致，误差均低于4e-9。

目标序列长度850–2784点。目标时间点插值比例中位数85.69%，范围0–97.14%；它反映原24–35 Hz视频映射到35 Hz网格时大多数网格点不是原始帧。读取器保存时间来源帧号、权重和观测标记；这些插值点不增加独立样本量。质量对照中预定包含该插值比例。

另对三种代表情形核验：35 Hz且8点、27 Hz且6点、31 Hz且有风险帧。35 Hz/8点病例的R序列与源正式R逐元素相等；风险帧对应及相邻插值区间没有被补成有效值。全295例验收输出见`sequence_input_acceptance_summary.json`和`sequence_input_acceptance_295.csv`。
